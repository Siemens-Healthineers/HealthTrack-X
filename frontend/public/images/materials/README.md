# Material Images

Place your custom images here. Supported formats: `.png`, `.jpg`, `.svg`, `.webp`

## Expected filenames

| Material | Filename |
|---|---|
| Raw Material | `raw-material.png` |
| Semi-finished Good | `semi-finished-good.png` |
| Label | `label.png` |
| Packaging | `packaging.png` |
| Surfaces/Coatings | `surfaces-coatings.png` |
| Cabelling | `cabelling.png` |
| PCBA | `pcba.png` |
| Standard Parts | `standard-parts.png` |
| Catalog Parts | `catalog-parts.png` |
| Custom Parts | `custom-parts.png` |
| Internal Design | `internal-design.png` |
| Medical Device | `medical-device.png` |
| Auxilliary Materials | `auxilliary-materials.png` |
| Consumables | `consumables.png` |
| Operating Materials | `operating-materials.png` |
| Additives | `additives.png` |
| Hazardous | `hazardous.png` |

## Tips

- Recommended size: **128×128 px** or larger (will be scaled down)
- Use **transparent background** (PNG/SVG) for best results on colored cards
- Images work in both dark and light mode
- If an image file is missing or broken, the lucide icon is shown as fallback
- You can change the file extension in `OverviewPage.tsx` → `IMAGE_MAP`
